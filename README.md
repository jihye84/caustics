# 빛그물 — 코스틱스 감상실

빛이 휘어진 표면에서 꺾이거나 반사되어 한곳에 모일 때 생기는 밝은 무늬, **코스틱스(caustics)** 를 직접 만들어 보는 웹앱입니다.

👉 https://jihye84.github.io/caustics/

## 장면
| 장면 | 유형 | 해 볼 것 |
|---|---|---|
| 물결 무늬 | 굴절 코스틱스 | 하늘색 수영장 바닥·골판 유리·빗방울 표면, 화면을 눌러 물결 일으키기, 분산(무지개) |
| 유리잔 | 굴절 + 분산 | 물컵·물 담은 컵·와인잔·브랜디잔·크리스털 잔·유리구슬 중 골라 비교, 빈 곳을 끌면 해가 움직이고 잔을 끌면 기울어짐 |
| 자수정 | 굴절 + 분산 | 자수정 기둥(돌리기·기울이기)·누운 자수정(여러 방향으로 굴리기·돌리기)·자수정 무리, 투명 수정에서 짙은 보라까지 색 조절 |

## 원리
- 물결 장면: 물 표면을 촘촘한 격자로 나누고 각 점에서 굴절된 빛이 바닥에 닿는 곳을 계산한 뒤, 격자 넓이가 줄어든 만큼 밝게 칠합니다(WebGL2).
- 유리잔 장면: 잔은 화면의 픽셀마다 광선을 쏘아 굴절·반사를 따라가며 그리고(광선 추적), 식탁 위 빛은 해 쪽에서 촘촘한 '빛 격자'를 쏘아 잔을 통과한 뒤 떨어지는 자리의 넓이 변화로 밝기를 계산합니다. 파장 6개로 나눠 계산해 무지개 테도 생깁니다.
- 자수정 장면: 석영 결정을 육각기둥과 뾰족한 머리(평면 여러 장으로 둘러싼 다면체)로 만들고, 수정의 굴절률(1.544)로 유리잔과 같은 방식으로 계산합니다. 결정 속을 지나는 거리만큼 보랏빛이 짙어지고, 어느 각도로 굴려도 가장 낮은 꼭짓점이 식탁에 닿습니다.
- 분산: 파장 8개마다 굴절률을 조금씩 다르게 주어 색이 갈라지게 했습니다(슬라이더로 과장 가능).

## 기타
- 한 파일(`index.html`)로 동작하며 외부 라이브러리를 쓰지 않습니다.
- 카카오톡·네이버·페이스북 등 인앱 브라우저에서 열면 기본 브라우저로 다시 엽니다(아이폰은 안내 화면).
- 어떤 화면 크기에서도 페이지 스크롤이 생기지 않게 만들었습니다. 조절 창은 바깥을 누르면 닫힙니다.

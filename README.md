# 빛그물 — 코스틱스 감상실

빛이 휘어진 표면에서 꺾이거나 반사되어 한곳에 모일 때 생기는 밝은 무늬, **코스틱스(caustics)** 를 직접 만들어 보는 웹앱입니다.

👉 https://jihye84.github.io/caustics/

## 장면
| 장면 | 유형 | 해 볼 것 |
|---|---|---|
| 물결 무늬 | 굴절 코스틱스 | 수영장·골판 유리·빗방울 표면, 화면을 눌러 물결 일으키기, 분산(무지개) |
| 커피잔 하트 | 반사 코스틱스 | 빛 방향 끌기, 빛까지 거리(네프로이드 ↔ 카디오이드), 반사 횟수 |
| 유리와 물방울 | 굴절 + 분산 | 유리 막대 뒤 뾰족점(cusp), 물방울 속 무지개(약 42°) |

## 원리
- 물결 장면: 물 표면을 촘촘한 격자로 나누고 각 점에서 굴절된 빛이 바닥에 닿는 곳을 계산한 뒤, 격자 넓이가 줄어든 만큼 밝게 칠합니다(WebGL2).
- 커피잔·유리·물방울 장면: 수만 개의 광선을 하나하나 반사·굴절시켜 그 빛을 더해 그립니다.
- 분산: 파장 8개마다 굴절률을 조금씩 다르게 주어 색이 갈라지게 했습니다(슬라이더로 과장 가능).

## 기타
- 한 파일(`index.html`)로 동작하며 외부 라이브러리를 쓰지 않습니다.
- 카카오톡·네이버·페이스북 등 인앱 브라우저에서 열면 기본 브라우저로 다시 엽니다(아이폰은 안내 화면).
- 어떤 화면 크기에서도 페이지 스크롤이 생기지 않게 만들었습니다.
